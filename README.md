# Retail Sales & Business Performance Analysis

## Project Overview
An interactive Excel dashboard project focused on analyzing retail sales and business performance using the Tableau Sample Superstore dataset.

The project explores sales, profit, regional performance, product categories, and monthly sales trends.

## Tools Used
- Microsoft Excel
- PivotTables
- PivotCharts
- Excel Formulas
- Interactive Slicers

## Dataset
- **Source:** Tableau Sample Superstore
- **Records:** 10,194 order records
- **Data:** Orders, customers, products, sales, discounts, and profits.

*Note: This is a fictional sample dataset used for analysis and learning purposes.*

## Key Analysis Performed
- Sales and profit analysis by product category.
- Regional sales and profit comparison.
- Monthly sales trend analysis.
- Product sub-category performance.
- KPI tracking for sales, profit, order records, and quantity.

## Dashboard Features
- Interactive KPI cards.
- Four PivotCharts.
- Region, Category, and Segment slicers.
- Dynamic filtering of charts and relevant KPIs.

## Project Files
- `Retail_Sales_Analysis.xlsx` – Main Excel dashboard and analysis workbook.

## Objective
To develop practical skills in data cleaning, data analysis, dashboard creation, and business performance reporting using Microsoft Excel.
